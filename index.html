⚙️ Como Conectar na Meta WhatsApp Cloud API Oficial

Siga o roteiro oficial para conectar o número de WhatsApp da lanchonete diretamente ao robô com inteligência artificial:

1
Criar App no Meta Developers: Acesse developers.facebook.com, crie um aplicativo tipo "Empresa" e adicione o produto WhatsApp.
2
Configurar Webhook e Chave de Verificação: Cole a URL de Webhook do seu servidor e o Verify Token para autenticar mensagens recebidas instantaneamente.
3
Conectar com a API do Google Gemini: O backend recebe o texto da mensagem do cliente via webhook, consulta o cardápio no Gemini 2.5 Flash, que formula a resposta e anota os itens estruturados.
4
Sincronização com o Thom's Lanches: Assim que o cliente confirma o endereço e a forma de pagamento, o pedido é disparado diretamente para o Kanban de Entregas e o KDS da Cozinha.
